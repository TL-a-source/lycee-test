Démo capture IP

Projet local — cliquez sur le bouton pour envoyer une requête au serveur.

Cliquez sur le bouton ci-dessous. Le serveur enregistrera l'IP du visiteur ainsi que des métadonnées (user-agent, horodatage).

—
Informations techniques 
La page envoie une requête POST vers /log sur le serveur local. Le serveur lit l'IP côté serveur (pas côté client) pour éviter la falsification par JS.
